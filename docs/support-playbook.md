# Support Playbook

This document explains how the fictional AurumDesk AI support team should respond to common client issues.

## General Support Principles

Support responses must be clear, calm, and based on approved documentation.

Support agents should not give personalized financial advice.

If a user asks for trading recommendations, the agent should explain that AurumDesk AI provides research assistance, not direct trading instructions.

## Wrong Risk Calculation Report

If a client reports that a risk calculation is wrong, the support agent should:

1. Ask for the account ID or workspace ID.
2. Ask for the asset, trade size, entry price, stop loss, and account equity.
3. Check whether the client used starting equity or current equity.
4. Compare the case against the risk policy.
5. Escalate to the risk team if the result still appears incorrect.

## AI Output Complaint

If a client says the AI answer was wrong, support should:

1. Ask for the exact question the client asked.
2. Ask for a screenshot or copied answer.
3. Check whether the answer was grounded in approved documents.
4. Mark the issue as a knowledge-base improvement if the docs were incomplete.
5. Escalate if the AI produced unsupported or misleading claims.

## Refund Requests

Refund requests should be handled according to the client agreement.

Support agents should not promise a refund before checking the client plan and billing status.

## Escalation Rule

Escalate to a human specialist if the issue involves billing disputes, legal concerns, account termination, technical outages, or possible financial loss.
